# Dove Global Tours & Travel Agencies Ltd
1. `npm install`  2. copy `.env.example` to `.env` and add EmailJS keys  3. `npm run dev`
Images: put your photos in `public/images/` (hero.jpg, about.jpg, amboseli.jpg, diani.jpg, nakuru.jpg, tsavo.jpg, lamu.jpg) 
Gallery: drop all gallery images (jpg, png, webp, jfif...) into `src/assets/gallery/`. They load automatically. Optional category prefixes: bigcats-, wildlife-, migration-, landscape-, travellers-.
EmailJS template variables: name, email, phone, service, date, guests, message.
